# UX Guidelines

- Preserve familiar navigation and return paths; distinguish implemented routes from placeholders.
- Use visible labels, inline validation, pending state, and explicit recovery paths.
- Use textual status in addition to color; avoid hover-only functionality.
- Keep booking details and total price visible before a booking action and trust server-provided business values.
- Design mobile-first and verify at narrow and desktop widths.
- Honor keyboard navigation and `prefers-reduced-motion`.
- Do not use toast as the only channel for important validation or persistent status.
