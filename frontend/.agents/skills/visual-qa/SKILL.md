# Visual QA Workflow

1. Identify changed routes and their intended access roles.
2. Verify a narrow/mobile viewport and a desktop viewport.
3. Check text hierarchy, token use, overflow, focus visibility, labels, and status text.
4. Exercise loading, empty, error, disabled, and success states where practical.
5. Check browser console for runtime errors and preserve business behavior.
6. Report observed results accurately; do not claim a screen-reader audit unless one was performed.
